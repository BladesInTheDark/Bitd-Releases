# BOOTH Library Gallery (GitHub Pages)

This `gh-pages` branch publishes a single self-contained page — `index.html` — via GitHub Pages.

- Live URL: https://bladesinthedark.github.io/Bitd-Releases/
- Thumbnails load live from booth.pximg.net (not embedded), so the file stays ~1.4 MB.
- This branch is intentionally separate from `main` (which manages tool release version files), so the release history stays clean.

## Updating the gallery
Replace `index.html` on this branch with a newly built copy and push. GitHub Pages redeploys automatically.
